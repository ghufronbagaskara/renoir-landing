## Reproduce verification

Run `bun run build`, `bun run serve`, then `node scripts/check-mobile-layout.mjs http://127.0.0.1:4322`.

The check uses the built search catalogue plus the 404 page, covers 320, 360, 390, 430, 600, 767, 768, 820, 1024 and 1440px, and checks document overflow, heading overflow, image loading, compact header geometry, mobile form labels/font sizes, FAQ icon containment, CTA placement and the retained two-column catalogues. It saves 390px screenshots and results under ignored `.work-capture/mobile-polish/after/`. The original local captures are under `before/`.

The EN/ID interaction checks exercise menu open/Escape/background inertness, search empty results/Escape, all four service selections, Process tap/keyboard, engagement and FAQ expansion, native empty-form validation and no-JavaScript Process/Work fallbacks. Real contact delivery requires the Worker and is not exercised by this asset server.

`scripts/check-motion.mjs` now checks the visible mobile Process disclosures and retains the desktop finite-stroke checks. Existing Home refresh/feedback and Work badge checks provide additional timing, navigation and containment coverage.
