Copy lebih banyak menjelaskan cakupan daripada menunjukkan pekerjaan yang akan terbantu. Revisi menggunakan headline lebih konkret, screenshot lebih dominan, ukuran teks yang bervariasi, serta komposisi khusus untuk tiap studi. Tidak ada klaim ROI, hasil penjualan, atau testimoni tambahan.

## Animasi: diagnosis dan tindakan

Pemilik mengalami masalah pada Microsoft PowerPoint desktop dalam mode Slide Show. Pemeriksaan terhadap file master v2 yang tersimpan menemukan 38 transisi, efek gambar, dan `ShowWithAnimation = true`. Jadi efek tidak hilang dari file master yang diperiksa. File yang dibuka pemilik belum dicocokkan byte per byte, dan pengaturan/perilaku aplikasi ketika masalah terjadi belum teramati langsung. Jangan menyatakan penyebab pasti tanpa bukti tersebut.

Panel chat versi sebelumnya menampilkan gambar utuh per slide. Ekspor ulang dari panel itu tidak setara dengan file master native; hal ini menjadi kemungkinan jalur kehilangan animasi, bukan penyebab yang sudah dibuktikan pada file pemilik.

Versi 3 memakai Push Left selama 0,85 detik pada semua perpindahan, fade gambar 0,75 detik, maju manual dengan klik, dan `ShowWithAnimation` diaktifkan secara eksplisit lalu diperiksa kembali sesudah file dibuka ulang. Pemilik menerima tautan master PPTX, bukan ekspor pratinjau gambar. Dokumentasi resmi: [ShowWithAnimation](https://learn.microsoft.com/en-us/office/vba/api/powerpoint.slideshowsettings.showwithanimation), [mematikan/mengaktifkan animasi](https://support.microsoft.com/en-us/powerpoint/change-remove-or-turn-off-animation-effects-in-powerpoint).

Pemeriksaan pemutaran dan batasnya dicatat pada README setelah ekspor. Bila komputer pemilik masih menghilangkan efek pada file master v3, langkah lanjut adalah memeriksa file yang tepat dan pengaturan pemutar, tanpa mengubah pengaturan global Windows secara diam-diam.

## Bukti aplikasi

Layar baru berasal dari source Proteksindo yang dijalankan di laptop ini. Bootstrap, database SQLite simulasi, session, cache, media dan log berada di `.build/demo`, terpisah dari source aplikasi dan database operasional. Migrasi data lama/MySQL-only disesuaikan hanya pada harness demo. Integrasi HTTP diblokir dan tidak ada pengiriman pesan atau pemanggilan AI. Layar bukan hasil gambar ulang UI. Ini membuktikan tampilan lokal, bukan hasil bisnis atau keaktifan fitur di produksi.

Pemilik kemudian meminta kolom kosong diisi. Ditambahkan 16 proyek sintetis dan diverifikasi melalui ProjectSnapshot bahwa kedelapan tahap Kanban masing-masing memiliki sedikitnya dua kartu. Screenshot diulang setelah penambahan, dan layar detail memilih proyek dengan progres serta laporan. Data tambahan tidak pernah dipresentasikan sebagai proyek klien baru.

Pemeriksaan gerakan menemukan Push terlihat pada frame 4,00, 4,25 dan 4,50 detik dalam contoh video yang dirender PowerPoint. File master memiliki 37 transisi dan 42 efek gambar serta ShowWithAnimation aktif sesudah dibuka ulang. Otomasi UI Windows gagal diinisialisasi, sehingga ini merupakan bukti renderer PowerPoint dan bukan pemeriksaan Slide Show interaktif pada file yang sebelumnya dibuka pemilik.
